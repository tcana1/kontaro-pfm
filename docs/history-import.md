# Importing transaction history from Excel

Use this to bring in a categorized history from a spreadsheet (another finance app's export, your own tracking sheet, etc.). Go to **Settings → History**, upload the file, review the preview, then confirm.

Start from the template: [`pfm-import-template.xlsx`](../app/client/public/pfm-import-template.xlsx) (also available via the **Download template** link on that page). It has ten fictional rows and an *Instructions* sheet.

## Format

Accepted files: `.xls`, `.xlsx`, `.xlsm`, up to 3 MB. Only the **first sheet** is read; row 1 must be the header row.

| Column | Required | Notes |
|---|---|---|
| `Account` | yes | Account name. Accounts that don't exist yet are created, and you're asked to classify them (checking / credit card / tracking) after the import. |
| `Date` | yes | A real Excel date cell, or ISO text (`2026-01-31`). Avoid `dd/mm/yyyy` text: it may be read as `mm/dd`. |
| `Payee` | yes | Who you paid or who paid you. |
| `Category` | column required, value optional | `Group:Category`, e.g. `Food:Groceries`. Without a colon the group is `Others`. Leave the cell empty for uncategorized. |
| `Amount` | yes | A number (not text). Negative = money out, positive = money in. |
| `Status` | no | `pending`, `cleared` or `reconciled`. `ignored` keeps the row in account balances but excludes it from reports (useful for transfers between your own accounts). Anything else is treated as `pending`. |
| `Notes` | no | Free text. |

Header names are case-sensitive and must match exactly.

## Behaviour to know about

- Rows missing `Account`, `Date`, `Payee` or `Amount` are skipped; the preview lists them with the row number and reason.
- Categories and groups that don't exist yet are created.
- Re-importing the same file is safe: duplicates are detected and not inserted.

## Custom headers (API only)

`POST /transactions/import-excel` accepts a `column_mapping` form field (JSON) to map your own headers to the fields above, e.g. `{"account": "Bank", "purchase_date": "When", "payee": "Who", "category": "Cat", "amount": "Value"}`. The web UI always uses the default headers.

## Regenerating the template

The template is generated by `importer/scripts/generate_import_template.py` and checked against the importer in `importer/tests/utils/test_import_template.py`. If you change the expected columns, update the script, rerun it, and commit the new `.xlsx`.
